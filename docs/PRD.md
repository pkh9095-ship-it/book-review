# 사이트 설계도(PRD) — 책 한 장 (인스타 서평 만들기)

작성일: 2026-10-15 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

> 이 사이트는 "문의가 들어오는 사이트"가 아니라 **나 혼자 쓰는 도구**다.
> 그래서 기준을 손님의 동선 대신 **내 동선**으로 잡는다:
> 책을 다 읽고 → 빈칸을 채우고 → 미리보기를 보고 → 글 복사·이미지 저장 → 인스타에 올린다.

## 1. 한 줄 정의
책 정보와 밑줄 친 문장, 느낀 점을 빈칸에 채우면 인스타그램에 바로 올릴 본문 글과 정사각형 서평 이미지 한 장을 만들어 주는 나만의 서평 도구.

## 2. 손님
- 누가: 나 (독서 인스타를 하는 나 혼자)
- 어디서 알고 오나: 내가 직접 주소로 들어감 (휴대폰·컴퓨터 즐겨찾기)

## 3. 손님이 궁금한 것 (쓰기 전에)
1. 빈칸만 채우면 바로 인스타에 올릴 수 있는 글이 나오는지
2. 이미지 카드가 인스타 정사각형 크기로 예쁘게 저장되는지
3. 예전에 만든 서평을 다시 꺼내 볼 수 있는지

## 4. 믿게 할 증거 (실제로 있는 것만)
- 해당 없음 (나 혼자 쓰는 도구)
- 후기: (필요 없음)

## 5. 누르게 할 버튼 하나
- 버튼 이름: 서평 만들기
- 누르면: 오른쪽(휴대폰에선 아래)에 인스타 본문 글 + 이미지 카드 미리보기가 나오고, 그 아래에 "글 복사"·"이미지 저장" 버튼

## 6. 페이지 구성 (위에서 아래로, 한 페이지)
1. 첫 화면 — 한 문장 + 입력 빈칸 시작
2. 입력 칸 — 책 제목·저자·출판사 / 밑줄 친 문장 / 느낀 점·추천 대상 / 해시태그(직접 입력)
3. 미리보기 — 인스타 본문 글 + 정사각형 이미지 카드 1장
4. 내보내기 — "글 복사" 버튼 · "이미지 저장(PNG)" 버튼 · "내 서평 목록에 저장" 버튼
5. 내 서평 목록 — 이 브라우저에 저장한 서평들 (다시 열기 · 지우기)

## 7. 입력 칸 (문의 폼 대신)
- 책 제목 (필수), 저자, 출판사
- 밑줄 친 문장 (1~3개, 각 문장 옆에 쪽수 선택 입력)
- 느낀 점 (여러 줄)
- 이런 분께 추천 (한 줄)
- 해시태그 (내가 직접 쓴 것만 넣음, 자동 태그 없음)
- 개인정보 수집·이용 동의: 해당 없음 (서버로 보내는 정보 없음, 모두 내 브라우저 안에서만 처리)

### 결과물 모양 (자동 정리 규칙)
- **본문 글**: 📖 제목 / 저자 · 출판사 → 밑줄 문장(따옴표, 쪽수) → 느낀 점 → "이런 분께 추천" → 내가 쓴 해시태그. 빈칸은 자동으로 빠진다.
- **이미지 카드**: 정사각형 1장(1080×1080). 표지 사진 없이 글자만 — 밑줄 문장 하나 + 책 제목·저자. 밑줄 문장이 여러 개면 카드에 넣을 문장을 고를 수 있다.

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 가격: 무료 (나 혼자 사용)
- 시간: 해당 없음
- 위치: 웹 주소 (Vercel 배포 후 정해짐)
- 연락 방법: 해당 없음 (문의 칸 없음)

## 9. 이번에 넣지 않을 것
- AI가 서평 문장을 다듬어 주는 기능 (AI 사용료·키 설정 필요)
- 책 표지 사진 올리기 / 책 검색으로 표지 자동 가져오기
- 한줄평·별점 칸
- 기본 해시태그 자동 추가
- 여러 장 카드(캐러셀)
- 문의 칸·문의 폼 (문의는 인스타 DM으로)
- 온라인 저장(Supabase)·관리자 페이지(/admin)
- 회원가입·로그인
- 인스타에 바로 올리기(자동 게시)

## 10. 첫 화면 한 문장 후보
1. 다 읽은 책, 빈칸만 채우면 오늘의 서평 한 장.
2. 밑줄 친 문장을 인스타 서평으로.
3. 책을 덮은 그 자리에서, 서평 글과 카드를 한 번에.

## 11. 다음에 할 것
- 여러 장 카드(캐러셀) 만들기
- 한줄평·별점 칸
- 내 책 사진 넣기
- 카드 색 테마 몇 가지 중 고르기
- 저장한 서평 백업 파일로 내보내기·불러오기 (다른 기기로 옮기기)
- AI 문장 다듬기 (필요해지면)

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 따뜻한 (종이·커피 같은 포근한 느낌) · 참고 디자인: 없음 — 클로드가 정함
- 문의 저장: 아니오 → 문의 칸 없음
- 서평 저장: 내 브라우저에 저장 (localStorage — 이 기기·이 브라우저에만 남음, 서버 없음)
- 관리자 페이지: 없음
- 회원가입: 이번엔 아니요
- 이미지 저장: 브라우저 안에서 카드 그림을 PNG로 만들어 내려받기 (외부 서버로 보내지 않음)
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 '따뜻한' 분위기에 맞게 정하고 입력 칸 → 미리보기 화면부터 만든다
2. 본문 글 자동 정리, "글 복사", 정사각형 카드 "이미지 저장(PNG)"을 만든다
3. "내 서평 목록"(브라우저 저장 · 다시 열기 · 지우기)을 만든다
4. 휴대폰 화면에서도 쓰기 편한지 확인한다
5. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
6. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 확인 방법 · 사용자가 할 일
- 사용자가 직접 할 일(이때만 멈춤): GitHub·Vercel 로그인
